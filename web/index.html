How Cortex solves agent amnesia.

Conventional agent tools dump dozens of complete files into the prompt, overflowing the context window and diluting attention. Cortex extracts minimal 2-hop graph slices.

Structural AST + Epistemic Memory

Cortex synchronizes two layers. Layer 1 maps code symbols, imports, exports, and design system contracts using AST parsing. Layer 2 captures conversational decisions, invariants, and discovered gotchas.

// .project-cortex.json dual-layer node structure
{
  "id": "decision-redis-tokens",
  "layer": "episodic_memory",
  "targetNode": "src/auth/token.service.ts::TokenService",
  "status": "verified",
  "verifiedBy": "npm test auth.test.ts",
  "invariants": ["Sliding 15m TTL", "Zero DB lookups on JWT validation"]
}

Append-Only Event Sourcing

Monolithic memory files cause merge conflicts when multiple developers or agent swarms work in parallel branches. Cortex records atomic events to .cortex/ledger/*.jsonl that merge cleanly in Git without conflict.

// .cortex/ledger/event-172683921.jsonl

CLI Commands Quick Reference

cortex init

Scans your repository, parses the AST across all source files, and initializes the local graph and ledger.

cortex context <target>

Extracts a sub-2,500 token compacted context slice containing 2-hop interfaces, invariants, and gotchas.

cortex decision <title>

Records an architectural decision with optional verification gates into the append-only event ledger.
