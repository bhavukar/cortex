Cortex Documentation

Cortex is a local, dual-layer codebase knowledge graph and context engine designed for autonomous AI agents. It compresses multi-file repository dumps into sub-2,500 token precision slices while preserving architectural decisions and invariants.

Introduction

When AI coding agents (such as Claude Desktop, Cursor, Cline, or custom agent harnesses) work on complex software repositories, they face two fundamental bottlenecks:

  • Context Amnesia: When a conversation ends or context resets, the agent forgets past architectural decisions, known gotchas, and refactoring constraints.
  • Context Window Overflow: Traditional tools dump 10 to 30 full files (40,000+ tokens) into the context window, causing high latency, token exhaustion, and attention dilution.

Cortex solves this by building an in-memory Dual-Layer Knowledge Graph and an Append-Only Event Ledger directly inside your repository.

Layer 1: Structural Code AST

Parses exports, functions, classes, and design system tokens into a causal dependency DAG.

Layer 2: Epistemic Memory

Records architectural decisions, invariants, and discovered gotchas linked directly to AST symbols.

Installation & Setup

Install the Cortex CLI globally using npm, or run it directly using npx:

BASH 
# Install globally
npm install -g cortex-graph

# Or run directly via npx
npx cortex-graph init

Quickstart Tutorial

Follow these 3 steps to integrate Cortex with your codebase:

Step 1: Initialize Cortex in your repository

Run cortex init in your project root. Cortex scans all source files, constructs the initial AST topology, and creates .project-cortex.json and .cortex/ledger/:

BASH 
cd /path/to/your/project
cortex init

Step 2: Record an Architectural Decision

When you or an AI agent make an architectural choice, lock it into the episodic memory layer with an optional verification test:

BASH 
cortex decision "Use Redis for Token Revocation" \
  --target "src/auth/token.service.ts::TokenService" \
  --test "npm test auth.test.ts" \
  --invariant

Step 3: Query Sub-2.5k Token Context Slice

Extract a compacted context slice for any file or function. The compactor emits only 2-hop interfaces, verified invariants, and known gotchas:

BASH 
cortex context src/auth/token.service.ts

Dual-Layer Architecture

Cortex combines two distinct planes into a unified graph:

Mathematical Heuristic for 2-Hop BFS

Given a target node \(v\), the 2-hop subgraph \(G_2(v) = \{u \in V \mid d(v, u) \le 2\}\) isolates the immediate callers and callees. Cortex strips private implementations and retains only exported interface signatures and active invariants, reducing token payload by 95%–98%.

Zero-Conflict Event Sourcing

Instead of storing all decisions in a single mutable JSON file that causes Git merge conflicts across agent branches, Cortex uses an append-only event ledger in .cortex/ledger/*.jsonl. Each decision, test execution, or gotcha is an immutable event:

JSONL (.cortex/ledger/events-172683921.jsonl) 
{ "eventId": "evt-9f82b1", "type": "DECISION_RECORDED", "timestamp": "2026-09-20T10:00:00Z", "author": "agent-auth", "data": { "title": "Use Redis for Token Revocation", "targetNode": "src/auth/token.service.ts" } }
{ "eventId": "evt-9f82b2", "type": "GATE_PASSED", "decisionId": "evt-9f82b1", "testCommand": "npm test auth.test.ts", "exitCode": 0, "promotedTo": "INVARIANT" }

CLI Command Reference

The Cortex CLI provides commands for graph maintenance, context extraction, and ledger management.

Command Arguments / Flags Description
cortex init --force, --include <globs> Scans AST, builds knowledge graph, and initializes .cortex/ledger/.
cortex sync --watch Re-scans modified files and updates AST symbols in real-time.
cortex context <targetSymbol>, --max-tokens <n> Extracts a sub-2,500 token compacted context slice for the target.
cortex decision <title>, --target <sym>, --test <cmd>, --invariant Records an architectural decision with optional verification test.
cortex gotcha <title>, --target <sym>, --note <text> Records a critical bug warning or pitfall attached to a symbol.
cortex blast <fileOrSymbol> Calculates the 2-hop blast radius and upstream/downstream callers.
cortex mcp --stdio Starts the Model Context Protocol stdio server for IDE agents.

Model Context Protocol (MCP) Integration

Cortex natively exposes an MCP server over standard I/O (stdio), enabling Claude Desktop, Cursor, Cline, and other MCP clients to query context slices dynamically.

Claude Desktop & Cursor Configuration

Add the Cortex MCP server to your client configuration file:

JSON (claude_desktop_config.json / .cursor/mcp.json) 
{
  "mcpServers": {
    "cortex": {
      "command": "npx",
      "args": ["-y", "cortex-graph", "mcp"],
      "env": {
        "CORTEX_ROOT": "/path/to/your/project"
      }
    }
  }
}

Exposed MCP Tools

Tool Name Parameters Return Value
cortex_get_context targetSymbol (string), maxTokens (optional number) Sub-2.5k compacted context slice with signatures and active invariants.
cortex_record_decision title (string), targetNode (string), invariants (string[]), testCommand (optional string) Confirmation object with event ID and verification gate status.
cortex_record_gotcha title (string), targetNode (string), note (string) Recorded gotcha event logged to ledger.
cortex_blast_radius targetSymbol (string) List of direct callers, downstream dependencies, and affected tests.
cortex_sync None AST refresh summary with count of added/updated symbols.

Programmatic TypeScript SDK

You can embed Cortex directly into custom Python or TypeScript agent harnesses using the exported programmatic APIs:

TYPESCRIPT 
import { CortexEngine, CompactorEngine, LedgerStore } from 'cortex-graph';

// 1. Initialize Graph Engine
const engine = new CortexEngine('/path/to/project');
await engine.initialize();

// 2. Query 2-Hop Blast Radius
const blastRadius = engine.getBlastRadius('src/auth/token.service.ts::TokenService');
console.log('Affected Callers:', blastRadius.callers);

// 3. Generate Compacted Context Slice
const compactor = new CompactorEngine(engine);
const contextSlice = await compactor.compact({
  targetSymbol: 'src/auth/token.service.ts::TokenService',
  maxTokens: 2500
});

console.log('Emitted Token Count:', contextSlice.tokenCount); // e.g. 1,180 tokens
console.log('Invariants:', contextSlice.invariants);
