SYSTEM SPECIFICATIONS

Self-Evolving Learning Loops

How Cortex continuously adapts, verifies, and prunes project knowledge automatically.

01

Automatic AST Invalidation

File watchers run localized Tree-sitter diffs on file saves. Modified exports, renamed types, and deleted methods update graph edges instantaneously.

02

3-Tier Verification Gates

New agent insights start in a tentative state. They are promoted to verified status only when test suites pass (exit 0), preventing hallucinated notes from poisoning memory.

03

Append-Only Event Ledger

Memory updates write to chronological delta files in .cortex/ledger/. Multiple teammates and branches merge in Git with zero JSON merge conflicts.

04

Hebbian Reinforcement & Decay

Frequently retrieved decision nodes gain confidence weight. Transient debugging notes decay over time and are pruned, keeping prompt injection lightweight forever.
